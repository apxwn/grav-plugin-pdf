# Security policy

## Supported versions

The latest release gets fixes. Older releases are not patched — the plugin is one folder in
`user/plugins/pdf/`, so updating it is a file copy and a cache clear.

## Reporting a problem

Please **do not** open a public issue for a security problem. Write to
**kontakt@orthodox-dresden.de** with:

- the plugin version (`blueprints.yaml`, or the Admin plugin screen),
- your Grav and PHP version,
- what an attacker could do with it,
- and how to reproduce it, if you can.

You will get an answer within a week. Once a fix is released, the report is credited in
`CHANGELOG.md` unless you would rather stay unnamed.
